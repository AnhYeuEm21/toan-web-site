# 📐 Sổ Tay Toán 11 (KNTT) - Lượng Giác & Dãy Số

> Website sổ tay học tập trực quan môn Toán 11 (Bộ sách Kết nối tri thức với cuộc sống), tổng hợp toàn bộ kiến thức Chương I (Hàm số & Phương trình Lượng giác) và Chương II (Dãy số) từ A đến Z.

## 🌟 Điểm nổi bật
- **Giải thích trực quan từ gốc rễ**: Khái niệm góc lượng giác, radian, đường tròn đơn vị, bản chất hàm chẵn/lẻ, tính tuần hoàn, dãy số tăng/giảm và bị chặn.
- **Minh họa SVG**: Tích hợp đồ thị sóng sin, cos và sơ đồ đường tròn lượng giác trực tiếp.
- **Thư viện SGK**: Đầy đủ 21 trang sách giáo khoa gốc có thể phóng to xem chi tiết.
- **Bẫy đề thi & Lưu ý**: Chỉ ra các bẫy thường gặp trong đề kiểm tra giữa kì & cuối kì (bẫy khai căn góc phần tư, bẫy tập xác định đối xứng, bẫy điều kiện xác định tan/cot, bẫy thử dãy số bằng Casio).
- **Thực chiến Casio FX-580 / FX-880**: Hướng dẫn bấm CALC rút gọn biểu thức, quét TABLE tìm min/max.
- **10 câu trắc nghiệm vận dụng cao**: Kèm lời giải chi tiết từng bước.

## 🚀 Hướng dẫn chạy
Trang web là ứng dụng tĩnh (Static HTML/CSS/JS), chỉ cần mở file `index.html` trên bất kỳ trình duyệt nào hoặc deploy trực tiếp lên Vercel / GitHub Pages.
